## Solace Advocates

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

Install dependencies

```bash
npm i
```

Run the development server:

```bash
npm run dev
```

### Solace API

The solace api is hosted on https://api.solace.alfonsoaranzazu.com and features the following endpoints:

- /advocates (Retrieves an array of advocates, supports query params name, specialty, city)
- /filters (Retrieves constant city and specialty values)
